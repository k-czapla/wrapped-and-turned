# Canva reference image

To use **your** Canva board design as the "Canva style" board background:

1. In Canva, export your board as **PNG** (with or without sample content).
2. Save it here as: **`canva-reference-board.png`** (same folder as this README — `frontend/public/`).
3. Restart or refresh the app; the "Canva style" design will use your image as the board background.

The app serves the file at `/canva-reference-board.png`. You can remove the file or keep it for comparison.
