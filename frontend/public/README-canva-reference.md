# Canva reference image (Option B PoC)

To use **your** Canva board design as a visual reference:

1. In Canva, export your board as **PNG** (with or without sample content).
2. Save it here as: **`canva-reference-board.png`** (same folder as this README — `frontend/public/`).
3. Restart or refresh the app; the Board Design page will show your image next to the "Canva style" option so we can tune the in-app design to match.

The app will serve the file at `/canva-reference-board.png`. Once the style is tuned to match your reference, you can remove the file or keep it for comparison.
